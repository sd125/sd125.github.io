一、適用範圍與用途

本政策說明「台股每日收盤資料」透過 Google Apps Script 與維護工具處理資料的方式。目前用途為個人自用市場資料蒐集、試算表整理、交易紀錄管理、策略觀察、配息試算與報表寄送；不是開放公眾上傳投資資料的金融服務。

二、處理的資料

  1. 試算表資料：使用者設定的帳戶分類、股票代號與名稱、股數、成本、交易紀錄、策略條件、公司行動確認、配息資格與實際入帳資訊，以及由此計算的結果。
  2. 市場資料：行情、ETF 持倉、淨值、股利公告、籌碼、經濟與能源指標、事件、新聞及來源日期。
  3. 郵件與收件設定：設定的報表收件地址；為核對是否已寄送與清理舊報表，程式搜尋郵件、檢查符合條件的主旨和日期，並把指定的舊報表郵件移至 Gmail 垃圾桶。它不以分析一般私人通信作為功能。
  4. 執行資料：觸發器、重試狀態、時間戳記、錯誤、資料品質與執行記錄。依記錄內容，可能包含股票代號、工作表名稱、報表狀態或請求資訊。
  5. 授權與來源憑證：Google OAuth 授權由 Google 與所使用的授權工具處理；市場資料 API 金鑰由使用者設定。Google 密碼不應寫入試算表或本程式。API 金鑰與 OAuth 權杖不得放到公開網站、公開程式庫或審查展示影片。

三、Google 權限與限制

目前 Apps Script 需要試算表存取、外部請求、郵件寄送、排程管理及 Gmail 存取權限，以完成上述功能。

試算表授權在技術上可能涵蓋多個試算表，但程式用途限於使用者設定的本系統檔案。Gmail 所宣告的完整郵件範圍也比目前功能更廣，包含授權畫面所描述的讀寫與刪除能力；目前已檢視的程式使用郵件搜尋、報表寄送狀態檢查與移至垃圾桶，未使用永久刪除郵件的功能。不得把「目前沒有呼叫」誤解成授權本身不具該能力。

本機 clasp、Apps Script API 或 Google Cloud 維護作業，可能另外需要程式內容、部署、Drive 檔案／中繼資料、Cloud 記錄或服務設定權限。這些作業僅供已授權的專案維護用途；若未來開放其他使用者，必須先核對實際用戶端所要求的全部範圍，更新揭露並取得必要同意。

四、資料的使用與傳送

資料用於提供使用者要求的試算表整理、計算、報表、排程與問題排查，不用於廣告投放、出售個人資料或建立與功能無關的個人剖析。

  • Google Sheets、Apps Script、Gmail 與 Cloud Logging 等服務，依實際啟用功能處理及儲存相應內容。
  • 市場資料請求會傳送至所設定的交易所、投信或資料供應商，例如查詢所需的股票代號、日期與該供應商的 API 憑證。程式功能不需要把持股成本、完整交易紀錄或私人郵件內容傳給行情網站。
  • 報表郵件依收件設定傳送；若使用者另設定其他收件人，該收件人將能看到報表內容，應先核對地址與內容。
  • 排錯及維護可能由使用者授權的工具讀取試算表、程式或記錄。若使用 ChatGPT、Codex 或其他連接服務協助分析，該服務的連線、資料處理與隱私設定另受其政策及使用者授權管轄，不得將此政策解讀為已替其他服務取得概括同意。

本應用程式不以 Google API 取得的資料訓練一般用途 AI 模型。對 Google API 資料的使用及必要傳送，應遵循 Google API Services User Data Policy，包括有限使用要求。

五、儲存與保留

主要市場與帳務資料儲存在使用者指定的 Google 試算表；設定及執行狀態可能儲存在 Apps Script 指令碼屬性、快取與執行記錄；授權維護作業也可能在使用者本機保留程式備份、測試及修復紀錄。

部分市場快照、ETF 資料及記錄依各資料集的交易日或日曆日規則清理，不是所有資料永久保存。交易、公司行動及實收配息等原始紀錄會影響成本及累計損益，不應在未備份及確認影響前任意刪除。精確保留期間以上線時的實際設定與畫面說明為準，不能把單一「30日」套用到全部資料。

符合條件的舊報表會移至 Gmail 垃圾桶；之後的保留與刪除由 Gmail 機制及使用者操作決定。試算表自動清理與郵件保留是不同機制。

六、停止使用、撤回與刪除

使用者可停止本程式觸發器、停用外部連接，並在 Google 帳戶的第三方連線設定中撤回存取權。撤回授權可能使排程失敗，但不等於自動刪除已存在的試算表、郵件、記錄、本機備份或另外連接服務中的資料。

如需刪除，應先停止排程與備份所需內容，再由有權限的使用者刪除相應試算表、郵件、指令碼屬性、執行記錄及本機檔案；涉及第三方服務的副本，需依各服務提供的方式另行處理。相關問題可透過本政策聯絡信箱洽詢。

七、網站與安全

本品牌網站由 GitHub Pages 代管，僅提供靜態功能與政策說明，不嵌入私人試算表或市場報表，不放置 API 金鑰與授權權杖。本站不提供 Google 登入表單、不載入分析追蹤程式、廣告或第三方字型。GitHub 會為提供服務及安全目的處理網站請求與訪客 IP 等技術資訊，相關處理依 GitHub 隱私權聲明。網站與其公開儲存庫只有說明頁面，不包含私人的 Apps Script 原始專案或帳務資料。

應限制試算表及 Cloud 專案的共用權限，保護憑證並避免記錄完整敏感請求。這些措施不代表可以保證零風險、永久有效的授權或任何特定安全認證。
